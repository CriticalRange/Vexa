# SDL2 frame interval instrumentation

`VEXA_FRAME_STATS=1` enables an opt-in counter in the SDL2 managed EGL swap path. It records the time between successful `eglSwapBuffers` completions on each thread and surface, in separate non-overlapping windows of 256 intervals, with average, p50, p95, p99 and maximum. Failed swaps and surface changes reset the window, preventing mixed surfaces or failed presentations from being counted. Long intervals are retained. This is CPU-side successful swap completion cadence, not GPU execution time or physical display present time. The final partial window is not reported.

The Android arm64 SDL2 host thunk built successfully. A native arm64 test compiled the exact counter function from the source and ran on the device: 256 synthetic 10 ms intervals yielded p50/p95/p99/max 10 ms; after a failed swap and change of surface, 255 synthetic 20 ms intervals and one 2000 ms interval yielded p50/p95/p99 20 ms and max 2000 ms. This checks arithmetic, resets and long-interval retention but is not an actual EGL/game integration test. The candidate APK assembled successfully using the existing FEX-2610 experimental build path, whose old FEX compatibility/staging checks are still bypassed. It was not installed because an existing Megabonk run was paused on device.

Megabonk's running process did not map the SDL2 host thunk, so this SDL2 instrumentation cannot currently measure it. It did map both `files/thunks/host/libGL-host.so` SHA-256 `f6b38f1cdde8656b8e107ce93ca07cb5ea130f7121266f2e8dc09e1f4a60552b` and an older separate `files/thunks/host/libGL.so.1` SHA-256 `56e68fb7f07953c8696f02105a9024ae3dda306d40d3d32933357b84876fb6e6`; the latter is an arm64 ELF with SONAME `libGL-host.so` and an `eglSwapBuffers` import. Their actual dispatch and ownership need tracing before changing or replacing either file. The untracked alias is a concrete lead, not yet proof that it presents frames or that it caused the missing counters. Next validate this instrumentation with a real SDL2 thunk-driven app and identify the Megabonk swap path independently.
